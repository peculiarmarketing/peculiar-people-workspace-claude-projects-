# SPEC: How to Type Around a Circle in Illustrator

- Title: How to Type Around a Circle in Illustrator
- Channel: Pixel & Bracket Illustrator Tutorials
- URL: https://www.youtube.com/watch?v=Cz5Q4C5eVaI
- Upload date: 2023-09-01
- Duration: 8:38
- Why this video: the only source in the set that walks through top text and bottom text on a split circle (flip, baseline vs ascender vs center alignment), which is exactly the seal's type construction.

Readers: one (reader A, transcript plus 160x90 storyboard). Gemini pass did not run, so every line is SINGLE SOURCE (reader A).

## Principles

- SINGLE SOURCE (reader A): For badge-style top and bottom text that both read correctly, split the circle into two halves; text on one closed circle cannot read upright at both top and bottom.
- SINGLE SOURCE (reader A): Split with the Scissors tool ("C") at "these two horizontal anchor points" (3 and 9 o'clock).
- SINGLE SOURCE (reader A): Use Type on a Path, not Area Type; clicking a closed shape with the Type tool can produce area type.
- SINGLE SOURCE (reader A): The click point sets the text start; in and out brackets set start and end; a midpoint bracket moves the whole run.
- SINGLE SOURCE (reader A): To centre top text: drag the in and out brackets to the two end anchor points of the half circle, then set paragraph alignment to Center. Then nudge "to get it visually correct" if needed.
- SINGLE SOURCE (reader A): Bottom text first reads "the wrong way"; fix with Type > Type on a Path > Type on a Path Options > Flip.
- SINGLE SOURCE (reader A): After Flip the text sits inside the circle; "instead of Baseline we're going to do Ascender which puts it on the outside of the path".
- SINGLE SOURCE (reader A): The speaker's recommendation for top plus bottom text is to align both to "Center" of the path ("my recommendation is if you're doing this type of top and bottom type on a path I would put it in the center"). Center alignment means the text is "centered to the path", i.e. the drawn circle runs through the middle of the letters.
- SINGLE SOURCE (reader A): Make top and bottom text the same point size ("now the text on bottom matches the text on top"); bottom text may need size or spacing changes to fit.
- SINGLE SOURCE (reader A): Re-align the two half circles so they meet exactly at their anchor points again.
- SINGLE SOURCE (reader A): Effect setting "Rainbow" is the one he leaves on (others: Skew, 3D Ribbon, Stair Step, Gravity).
- SINGLE SOURCE (reader A): Decorations can be added between the text runs, and type can go in the centre. On screen the decorations are small dots at 3 and 9 o'clock.

## Numbers

- SINGLE SOURCE (reader A): "100 is the point size" (final text size on his artboard; artboard dimensions not given, so not a print size).
- SINGLE SOURCE (reader A): Alignment options listed exactly: "Ascender", "descender", "baseline", "center".
- SINGLE SOURCE (reader A): Shortcuts: Ellipse "L", Type "T", Scissors "C", Selection "V"; "shift" for a perfect circle; "alt or option" drag to duplicate.

## Demonstrated vs said

- SINGLE SOURCE (reader A), shown: full-circle placeholder text, flip preview, alignment preview, scissors split, top text centred via brackets plus paragraph centre, bottom text flipped, realigned and resized, final badge with dots at the sides.
- SINGLE SOURCE (reader A), said only: centre type, character-panel spacing adjustments, Gravity effect behaviour.

## Caveats

- SINGLE SOURCE (reader A): Centring by brackets is approximate; optical nudging is part of the method.
- SINGLE SOURCE (reader A): The speaker mis-clicks the bracket handles on camera; the handles are fiddly.

## Archetype trap flags

- Kerning or tracking compensation on curved text (tighten outer, loosen inner) is NOT in this video. Do not attribute it here.
- "Bottom text reads left to right / counter-clockwise flip" as a typographic rule is not argued; the video only shows the mechanic (Flip) and that the result is readable.
- Any minimum type size, ring weight, or print guidance would be imported; the video has none.
