# SPEC: Illustrator Typography Tips for Creating a Vintage Logo Design

- Channel: Spoon Graphics
- URL: https://www.youtube.com/watch?v=8smWim7c7t0
- Upload date: 2017-06-13
- Duration: 9:50
- Why this video: a type-led vintage badge build with stated values for all-caps tracking, arc bends, stroke weights and ornament spacing, plus a type hierarchy (heavy caps, script, tracked small caps) relevant to the seal.

Readers: A only (transcript + 160x90 storyboard). Gemini pass did not run, so every line is SINGLE SOURCE (reader A).

## PRINCIPLES

- SINGLE SOURCE (reader A): Type-based badges need a deliberate font set: "a heavy geometric sans [serif] a nice flowing script and a narrow industrial sans [serif] all complement each other."
- SINGLE SOURCE (reader A): Arc/rise envelope effects "are the key ingredient of vintage style designs."
- SINGLE SOURCE (reader A): Stack lines with alternating curvature: top word arcs one way (+10), a line below arcs the other way (-10).
- SINGLE SOURCE (reader A): Small all-caps secondary line is widely tracked (tracking 400) and scaled down under the main words.
- SINGLE SOURCE (reader A): Everything is centre aligned on one vertical axis, using a key object so the anchor element does not move.
- SINGLE SOURCE (reader A): Vertical spacing between elements should be "roughly the same" (by eye).
- SINGLE SOURCE (reader A): Two-line caps blocks: tighten line height/leading; kern so letters "line up ... along their left edges."
- SINGLE SOURCE (reader A): Paired side elements are scaled "to the same height" as the central block they flank and grouped so they centre "while maintaining the gap between them."
- SINGLE SOURCE (reader A): Ornament ring: stars blended along an offset copy of the border with a step count chosen for symmetry.
- SINGLE SOURCE (reader A): Final art is expanded and united into one vector shape before texturing.
- SINGLE SOURCE (reader A): Texture effects must not erase "the smaller parts of the design."

## NUMBERS

- SINGLE SOURCE (reader A): Tracking on "DESIGN BLOG" (small all caps): "400".
- SINGLE SOURCE (reader A): Arc bend on "SPOON": "10"; on "DESIGN BLOG": "minus 10"; "made in": "10 arc"; whole layout: "arc setting at ten percent".
- SINGLE SOURCE (reader A): Rise bend on "the" inside the diamond: "10".
- SINGLE SOURCE (reader A): Diamond: stroke "three points" with round corners, rotated "45 degrees", vertical non-uniform scale "50".
- SINGLE SOURCE (reader A): Hexagon border: stroke "8 points", round corners "10 pixels".
- SINGLE SOURCE (reader A): Star path offset: "20 pixels"; blend "specified steps" "41" ("in my example").
- SINGLE SOURCE (reader A): Document: "a4 art board with pixel units in the rgb color mode".
- SINGLE SOURCE (reader A): Photoshop: median "around 5 pixels"; ripple "around 20"; reticulation "4800" (as captioned); torn edges "37 1 and 17"; inner glow "normal black 100 opacity zero choke", size "around 24 pixels".
- SINGLE SOURCE (reader A): Fonts: "town 10 black", "montebello script", "urw din condensed".
