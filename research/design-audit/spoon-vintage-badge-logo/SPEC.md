# SPEC: How to Create a Vintage Badge Logo in Adobe Illustrator

- Channel: Spoon Graphics
- URL: https://www.youtube.com/watch?v=xv3u7AgeKec
- Upload date: 2021-09-28
- Duration: 10:43
- Why this video: a step-by-step build of a circular vintage badge with type on a circle, rings, stars and a diamond banner, the closest construction analogue to the jacket seal.

Readers: A only (transcript + 160x90 storyboard). Gemini pass did not run, so every line is SINGLE SOURCE (reader A).

## PRINCIPLES

- SINGLE SOURCE (reader A): Vintage badges rely "heavily on wording rather than imagery", so use fonts that "authentically replicate old hand lettering."
- SINGLE SOURCE (reader A): Pair styles from one family kit so fonts match without sourcing more.
- SINGLE SOURCE (reader A): Kern individual pairs manually after setting text (Alt plus left/right arrows).
- SINGLE SOURCE (reader A): Punctuation can throw off alignment: "The comma in this wording offsets the vertical alignment slightly so it's nudged into place optically."
- SINGLE SOURCE (reader A): Do not accept a warp that distorts letters: "the text is being warped out of shape too much. Undo." Reshape the container (cut the diamond points to straight edges) until the text fits.
- SINGLE SOURCE (reader A): Badge circle may overlap the central script and be snipped where the script crosses it.
- SINGLE SOURCE (reader A): "Altering a font's tracking value to space out the letters is a great way to fill up the available area without having to make the actual text size too big." (Tracking, not size, fills the arc.)
- SINGLE SOURCE (reader A): Bottom arc text is the top type-on-path duplicated, rotated 180°, flipped to read the right way up, then baseline shifted "to the outside of the path."
- SINGLE SOURCE (reader A): Text circle is a separate, slightly larger, unstroked circle from the visible ring.
- SINGLE SOURCE (reader A): Concentric rings are centred via outline mode and Alt-drag from the centre point.
- SINGLE SOURCE (reader A): Outer border: a second, slightly larger circle "with a much broader stroke" than the inner ring.
- SINGLE SOURCE (reader A): Ornaments in the type-on-path band are rotated about the circle centre "to follow the circular outline"; set mirrored on the other side.
- SINGLE SOURCE (reader A): Use a key object when aligning so the anchor element does not move; elements "sit perfectly centrally."
- SINGLE SOURCE (reader A): Final art is expanded, same-fill shapes united, compound paths made, white subtracted from black for "a continuous outline"; keep a live backup.

## NUMBERS

- SINGLE SOURCE (reader A): Script warp: envelope distort "rise", "bend value to 20%".
- SINGLE SOURCE (reader A): Secondary text arc: "the same 20% bend".
- SINGLE SOURCE (reader A): Diamond: square "rotate it by 45°", then non-uniform scale "300% for the horizontal value".
- SINGLE SOURCE (reader A): Bottom text circle "Rotate the circle by 180°".
- SINGLE SOURCE (reader A): "three stars" per side, mirrored (six total).
- SINGLE SOURCE (reader A): Diamond stroke alignment "outside".
- SINGLE SOURCE (reader A): Not given (by eye): ring stroke weights, outer border weight, tracking value, baseline shift, star rotation step, type sizes.

## CAVEATS

- SINGLE SOURCE (reader A): Artboard size does not matter.
- SINGLE SOURCE (reader A): Start with clean font variants; texture is a separate later step (Ink Stamp Texturizer PSD, a free Spoon Graphics download).
- SINGLE SOURCE (reader A): Compound paths are needed for the pathfinder subtract to work.
