## PRINCIPLES

- Vintage badge style: "based on the way brand identities were created in previous centuries with handlettered layouts that clearly describe the company, unlike modern logo designs of today that are condensed into a simple icon graphic." [00:00]
- "With vintage style designs relying so heavily on wording rather than imagery, it's important to use fonts that authentically replicate old hand lettering." [00:33]

- Kerning: "make any necessary kerning adjustments by placing the cursor and using the left and right keyboard keys while holding Alt to adjust the individual letter spacing." [02:38]
- Optical nudge: "The comma in this wording offsets the vertical alignment slightly so it's nudged into place optically." [03:10] (text inside a black rectangle; mathematical align was not used as final)
- Envelope distortion must not over-warp text: "notice how the text is being warped out of shape too much. Undo the effect." Fix: cut the diamond's points off with straight edges so "the text fits perfectly into the shape." [03:40 to 04:13]
- "Vintage logos can be layouts of text or contained within outlining shapes." [05:20]
- Circle overlapping the script: draw a circle "overlapping each end of the script slightly ... Give this circle a black stroke with an appropriate weight ... snip the path and delete the unwanted portions that overlap the script text." [05:51]
- Tracking on a circle: "Altering a font's tracking value to space out the letters is a great way to fill up the available area without having to make the actual text size too big." [06:23]
- Bottom arc text: duplicate the top type-on-path, "Rotate the circle by 180° to place the text on the bottom. Then adjust the alignment handle ... to place the text the right way up. While the text is now readable, it's set to the inside of the path. An easy fix is to adjust the baseline shift value to offset it to the outside of the path." [06:23 to 06:56]
- Centring rings: "A trick to line it up centrally is to turn on outline mode ... Alt and drag the shape from the center point." [06:56]
- Ring hierarchy: "Copy and paste this outlining circle to add another slightly larger border. This time with a much broader stroke." [06:56 to 07:26]
- Ornaments following the circle: star "is part of the type on a path area. So, rotate the star to follow the circular outline", using the rotate tool pivoted on the circle centre so "The pivot point will follow the rotation to keep the star lined up perfectly." [07:26]
- Key object alignment: give the diamond "an extra click to make it the key object so it doesn't move out of place. Align the shapes up so they sit perfectly centrally." [05:20]
- Final art for print: expand appearance and expand, unite same-fill shapes, make compound paths, then minus front white from black "leaving a continuous outline." Keep a live unexpanded backup. [07:57 to 09:05]
