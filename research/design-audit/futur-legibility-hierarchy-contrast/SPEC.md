- Why this video: a critique-format source for the "legibility beats decoration" and "design in black and white first" rules, relevant to auditing a one-colour seal.

## PRINCIPLES

- SINGLE SOURCE (reader A): "legibility should supersede any kind of decorative element that you do."
- SINGLE SOURCE (reader A): "Legibility should supersede every other consideration." The test given is a self-question: "is it legible? Does it read well?"
- SINGLE SOURCE (reader A): Reading the wordmark "supersedes all the other decisions that you're making."
- SINGLE SOURCE (reader A): "we don't want to use graphic elements purely for decoration. We want to reinforce and make the logo even more legible." (Example: bars on a TRIDENT wordmark should emphasise a syllable of the spoken word, not land arbitrarily.)
- SINGLE SOURCE (reader A): Modifying a letter so its terminal no longer matches the typeface (angling a straight sans terminal to follow a curve) "makes it look like that letter form is from some other typeface."
- SINGLE SOURCE (reader A): Cutting into a letter (the H in HUDLUM) can make it read as a symbol and drop out of the word ("read it as Udlam").
- SINGLE SOURCE (reader A): "Always work in black and white. No colors, no textures," to focus on "hierarchy, contrast, and legibility." ARCHETYPE TRAP: this is a very common piece of logo advice; the video asserts it but does not demonstrate the workflow.
- SINGLE SOURCE (reader A): For a symbol plus wordmark lockup, "the lockup is important"; suggested fix: mix two weights ("book in a lighter weight and then worm is in a bolder typeface").
- SINGLE SOURCE (reader A): "You don't want to illustrate what it does ... it's abstract, but it's clear what it is." ARCHETYPE TRAP: generic logo-school advice, here only voiced in passing.
- SINGLE SOURCE (reader A): Critique order: describe what is there (typeface, shapes, curves, points, line weights) with no judgement, then feelings, then improvement ideas.
