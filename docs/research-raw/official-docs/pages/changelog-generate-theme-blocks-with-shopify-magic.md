 May 21, 2025
 Generate theme blocks with Shopify Magic

 Shopify Magic now lets you generate any theme block you want, revolutionizing the way you customize your Shopify store. Simply describe what you want, and Shopify Magic will code the theme block on the spot.

Theme block generation is available on Horizon themes, and all themes that support theme blocks. 

Learn more about theme block generation in the Shopify Help Center.
