 December 10, 2025
 AI block generation for all Theme Store themes

 AI block generation, powered by Sidekick, now works with every theme from the Shopify Theme Store-not just Horizon themes. Describe what you want in plain language, and Sidekick will code it for you on the spot. And if Sidekick's first pass isn't just right, you can iterate on the design to refine your results.

Theme block generation is available on Theme Store themes. Learn more about theme block generation in the Shopify Help Center.
