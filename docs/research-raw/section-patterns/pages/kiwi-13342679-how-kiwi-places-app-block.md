# How Kiwi Decides Where to Place the Size Chart (App Block)

How Kiwi decides where your size chart appears on the product page, and which placement setting wins when more than one applies.

Updated this week

Table of contents

Kiwi uses a priority-based logic to make sure your size chart always appears somewhere on the product page, regardless of your theme setup.

Here’s how it works:

## 1️⃣ Custom Injection (Highest Priority)

If you’ve enabled Custom Injection in Style & Settings, Kiwi will try to place the size chart exactly where your selected injection target (CSS selector) appears on the product page.

Use this when:

- 

You need precise control

- 

You want to position the chart inline (e.g., next to the size selector)

## 2️⃣ App Block Placement (If Enabled)

If custom injection is not detected or is disabled, and you’ve enabled the Custom size chart placement toggle, Kiwi will show the chart where you’ve placed the Kiwi Size Chart app block in your Shopify theme editor.

Use this when:

- 

You want a simple, drag-and-drop setup

- 

You’re placing the chart between major product sections

## 3️⃣ Default Fallback Placement

If neither injection nor app block placement works (e.g., due to theme limitations), Kiwi will default to showing the size chart near the first “Add to Cart” form on the page. For merchants using Horizon or Dawn themes, the default position for the Size Chart button will be directly next to the Size variant label.

This ensures your size chart is still visible so your customers aren’t left guessing.

If your chart isn't showing where you expect, check which placement method is currently active. And remember: custom injection always overrides the app block if both are enabled.

Need help choosing the best option? Contact our support team, we're happy to review your setup!
