# Shopify Theme Extension Requirement – What It Means for You

Understanding the Shopify theme extension requirement and its impact on your store.

December 11, 2025

Table of contents

Shopify has introduced a new policy requiring all apps to use theme app extensions instead of injecting Liquid code directly into a store’s theme. This is a strategic move aimed at improving performance, security, and long-term manageability of your online store.

## What Are Theme App Extensions?

Theme app extensions are the modern, Shopify-recommended way for apps to integrate with your store’s theme. Instead of editing theme files, apps add features through modular blocks, embed blocks, and static assets. This method offers key benefits:

- 

No manual code edits – Merchants no longer need to touch Liquid templates.

- 

Easier to maintain – Updates are more stable and less likely to be broken by theme changes.

- 

More secure – Apps don’t directly alter your theme code.

- 

Faster to deploy – Install, configure, and position app blocks visually using the Shopify theme editor.

- 

Universal compatibility – One setup works across all compatible Online Store 2.0 themes.

## What This Means for Kiwi Size Chart & Recommender

Kiwi Sizing fully supports Shopify’s theme app extension framework. This ensures:

- 

Seamless integration using app blocks and embed features.

- 

No manual Liquid code is required during setup.

- 

Installation, updates, and uninstallation are simplified and leave no residual code.

- 

A faster, smoother experience for both merchants and shoppers.

You’ll continue to enjoy Kiwi’s full feature set:

- 

Responsive, customizable size charts

- 

Smart size recommendations powered by advanced algorithms

- 

Reduced returns and increased customer confidence
